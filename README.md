# Kando Menu Configuration

A customizable [Kando](https://kando.menu/) pie-menu configuration for quick access to apps, folders, system actions, and common desktop workflows.

## Menu contents

- **Brightness Audio Mic** — shortcuts for brightness, audio, and microphone actions.
- **App List** — launch VS Code, Konsole, Firefox, Settings, and Bruno.
- **Open URI** — four configurable URI shortcuts.
- **Change Wallpaper** and **Protonvpn** — standalone actions.
- **Folder** — open Downloads, Documents, Projects, and Home.
- **Power** — power off, reboot, sleep, lock, and log out.

## Use the configuration

Import `DefaultMenu.json` into Kando using its menu import option. The configuration uses menu format version `3.0.0`.

## Customize

Review the actions before using the menu on your system:

- The brightness, audio, and microphone entries have empty command fields. Add commands that are appropriate for your desktop environment.
- Update the URI targets and any application or folder paths to match your setup.
- Power actions and external commands depend on your operating system and permissions.
- Some entries reference custom icon names or themes. Replace them with icons and themes available in your Kando installation if needed.

For more information about Kando, visit [kando.menu](https://kando.menu/).
